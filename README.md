# 투자 포트폴리오 관리 (개인용)

증권사/계좌별 종목의 목표 비중과 분할매수 단계 대비 현재 평가금액을 비교해
리밸런싱 방향(확대/축소)을 보여주는 개인용 계산기입니다.

로그인/비밀번호 없음 (개인 전용 단일 사용자 앱). 서버 없이 브라우저에서만 동작하는 순수 정적 사이트입니다.

## 파일 구성 (박스별로 분리)

유지보수하기 쉽도록 화면의 박스 단위로 파일을 나눴습니다.

- `index.html` — 전체 뼈대(HTML)만 포함
- `style.css` — 전체 디자인
- `js/core.js` — 상태 관리 · 계산 로직 (모든 박스가 공유)
- `js/numpad.js` — 숫자 입력 팝업 (공통 UI)
- `js/settings-box.js` — "⚙️ 설정" 박스: 평가금액 합계 / 저장·불러오기 / File 내보내기·가져오기 / 초기화
- `js/stock-summary-box.js` — "📋 종목별 평가금액 요약" 박스: 파이 차트 + 종목별 합산 표
- `js/main-table-box.js` — "📊 계좌별 리밸런싱 현황" 박스: 메인 테이블
- `js/price-table-box.js` — "📌 종목별 현재가" 박스: 마스터 종목 테이블
- `js/stage-summary-box.js` — "📈 단계별 미달성 금액" 박스

## 데이터 저장 방식

- **자동저장**: 브라우저를 새로고침해도 마지막 작업 내용이 그대로 복원됩니다 (localStorage, 기기별로 별도 저장).
- **저장하기 / 불러오기**: 같은 브라우저의 localStorage에 명시적으로 저장/복원합니다.
- **File로 내보내기 / File에서 가져오기**: JSON 파일로 수동 백업·복원하거나, 다른 기기로 옮길 때 사용합니다.

## 배포 방법

이 폴더의 파일 전체(`index.html`, `style.css`, `js/` 폴더)를 그대로 GitHub Pages, Vercel, Netlify 등 어떤 정적 호스팅에 올려도 동작합니다. 별도의 서버 설정이나 환경변수가 필요 없습니다.

## 참고

데이터 구조가 처음에는 비어 있습니다. "종목별 현재가" 표에서 종목을 먼저 등록한 뒤, "계좌별 리밸런싱 현황" 표 아래에서 증권사/계좌를 추가하고 종목을 불러와 사용하세요.
