# 내 주식 평가금액 관리 앱

브라우저 정적 파일(`index.html`) + 서버리스 함수(`api/price.js`)로 구성된 앱입니다.
시세 조회는 서버(Vercel Functions)에서 대신 처리하므로 브라우저 CORS 제한 없이 동작합니다.

## 배포 방법 (GitHub + Vercel)

### 1. GitHub에 업로드
1. github.com에서 새 저장소 생성 (예: `portfolio-app`)
2. 이 폴더 안의 파일 전체(`index.html`, `api/price.js`, `package.json`)를
   저장소에 업로드 (웹에서 드래그 앤 드롭으로 가능: 저장소 페이지 → "Add file" → "Upload files")

### 2. Vercel에 배포
1. vercel.com 접속 후 GitHub 계정으로 로그인
2. "Add New" → "Project" → 방금 만든 GitHub 저장소 선택
3. 설정은 기본값 그대로 두고 "Deploy" 클릭
4. 1~2분 뒤 `https://프로젝트이름.vercel.app` 주소가 발급됩니다

이후 GitHub 저장소에 새로 업로드(커밋)할 때마다 Vercel이 자동으로 재배포합니다.

## 주의사항

- 시세 조회는 야후 파이낸스 공개 데이터를 이용한 비공식 방식이라 100% 보장되지는 않습니다.
  실패하면 종목 마스터 목록에 "조회 실패" 배지가 표시됩니다.
- 정확한 조회를 위해 종목명 칸에는 회사명보다 **티커**를 입력하는 걸 권장합니다.
  - 미국 주식: `AAPL`, `TSLA` 등
  - 한국 코스피: 종목코드 + `.KS` (예: 삼성전자 `005930.KS`)
  - 한국 코스닥: 종목코드 + `.KQ` (예: `035720.KQ`)
- 데이터는 각자의 브라우저(localStorage)에 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우면
  사라지므로, 상단의 "내보내기" 버튼으로 주기적으로 백업(JSON 파일)해두고,
  필요할 때 "가져오기"로 복원하세요.
