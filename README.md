# 투자 포트폴리오 관리 (개인용)

증권사/계좌별 종목의 목표 비중과 분할매수 단계 대비 현재 평가금액을 비교해
리밸런싱 방향(확대/축소)을 보여주는 개인용 계산기입니다.

- `index.html` — 화면 전체 (순수 HTML+CSS+JS, 외부 라이브러리 없음)
- `api/save.js`, `api/load.js` — 서버에 데이터를 저장/조회하는 서버리스 함수
- 로그인/비밀번호 없음 (개인 전용 단일 사용자 앱)

## 배포 방법

### 1. GitHub 업로드
이 폴더의 파일 전체(`index.html`, `package.json`, `api/` 폴더)를 GitHub 새 저장소에 업로드합니다.

### 2. Vercel에 배포
1. vercel.com → GitHub 로그인 → "Add New" → "Project" → 방금 만든 저장소 선택 → Deploy

### 3. 서버 저장 기능 활성화 (Vercel KV 연결) — 꼭 필요합니다
"저장하기"/"불러오기" 버튼은 Vercel의 KV(키-값) 스토리지를 사용합니다. 배포 후 한 번만 설정하면 됩니다.

1. 방금 만든 Vercel 프로젝트 페이지 → 상단 탭 **Storage** 클릭
2. **Create Database** → **KV** 선택 (Upstash 기반, 무료 티어 있음)
3. 데이터베이스 이름 입력 후 생성 → **Connect to Project**에서 이 프로젝트 선택 → Connect
4. 프로젝트가 자동으로 재배포됩니다 (환경변수 `KV_REST_API_URL`, `KV_REST_API_TOKEN`이 자동으로 주입됨)
5. 재배포가 끝나면 사이트에서 "저장하기"를 눌러보고, 다른 기기/브라우저에서 "불러오기"를 눌러 잘 불러와지는지 확인하세요.

이 토큰은 서버끼리만 쓰는 비밀값이라 사용자가 아이디/비밀번호를 입력할 필요는 없습니다.

## 참고

- 자동저장: 브라우저를 새로고침해도 마지막 작업 내용이 그대로 복원됩니다 (브라우저 localStorage 사용, 기기별로 별도 저장됨).
- "저장하기": 서버(Vercel KV)에 현재 상태를 저장합니다. 어느 기기에서나 "불러오기"로 동일한 데이터를 가져올 수 있습니다.
- "File로 내보내기" / "File에서 가져오기": JSON 파일로 수동 백업/복원할 때 사용합니다.
- 데이터 구조가 처음에는 비어 있습니다. "종목별 현재가" 표에서 종목을 먼저 등록한 뒤, "계좌별 리밸런싱 현황" 표 아래에서 증권사/계좌를 추가하고 종목을 불러와 사용하세요.
