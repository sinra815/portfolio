# 투자 포트폴리오 리밸런싱 계산기 — 서버 저장 버전

## 구조
- `server.js`: 외부 npm 패키지 없이 동작하는 Node.js 서버
- `public/index.html`: 웹앱
- `data/`: 서버에 저장되는 포트폴리오 JSON

## 실행
1. Node.js 18 이상 설치
2. 이 폴더에서:
   `node server.js`
3. 브라우저에서 `http://localhost:8080` 접속

## 여러 기기에서 공유
1. 한 기기에서 `☁ 서버 저장`을 누릅니다.
2. 포트폴리오 ID(예: `myportfolio`)와 비밀번호를 입력하고 저장합니다.
3. `🔗 서버 공유`에서 링크를 복사합니다.
4. 다른 기기에서 같은 웹앱 주소를 열고 포트폴리오 ID와 비밀번호를 입력합니다.
5. `☁ 서버 불러오기`를 누르면 서버의 최신 데이터가 표시됩니다.

## 인터넷에서 사용하려면
이 프로젝트를 인터넷에 공개되는 Node.js 서버에 배포해야 합니다.
예: VPS, 사내 서버, 또는 Node.js를 지원하는 호스팅.
HTTPS를 권장합니다.

## 중요한 점
현재 버전은 서버의 `data/*.json` 파일에 저장합니다.
- 비밀번호는 평문으로 저장하지 않고 salt + scrypt 해시로 저장합니다.
- 포트폴리오 데이터 자체는 서버 디스크에 JSON으로 저장됩니다.
- 실제 금융자산 정보를 인터넷에 저장할 경우 HTTPS, 인증, 백업, 접근제어를 갖춘 운영환경을 권장합니다.
- 공유 링크에는 비밀번호를 넣지 않았습니다.
