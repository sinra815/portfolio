# portfolio — Vercel 배포용

## 1. Vercel에 업로드
이 폴더 전체를 Vercel 프로젝트로 배포하세요.

## 2. 데이터베이스 연결
서버 저장/다른 기기 동기화를 사용하려면 Vercel KV 호환 저장소를 연결해야 합니다.
Vercel 대시보드에서 KV/Redis 저장소를 연결하고 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경변수가 프로젝트에 들어오도록 설정하세요.

## 3. 사용
배포 후 `https://배포주소/`로 접속합니다.
`☁ 서버 저장`에서 포트폴리오 ID와 비밀번호를 정합니다.
다른 기기에서도 같은 주소에서 같은 ID/비밀번호로 `☁ 서버 불러오기`를 누르면 됩니다.

주의:
- 비밀번호를 잊으면 복구할 수 없도록 설계했습니다.
- 포트폴리오 ID는 영문 소문자/숫자/_/- 3~40자입니다.
- 기존 로컬 저장(localStorage)과 JSON 내보내기/가져오기 기능도 유지됩니다.
