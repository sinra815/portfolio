조작
계산 로직 · 평가금액(M): 현금 행은 입력한 현금 금액(만원), 주식은 마스터 현재가(원) × 보유수량 ÷ 10,000. 계좌 총평가금액(D)은 해당 계좌의 M 합계입니다. 비중이 지정된 행은 입력 비중을 사용하고, 비중이 비어 있는 행(보통 현금)은 100 - 지정 비중 합으로 자동 배분합니다. 목표금액(G)=D×목표비중/100. 주식 목표금액은 선택한 단계(stage)를 곱하고, 현금성 자산은 항상 100% 목표로 계산합니다. 차액(N)=목표금액-현재 평가금액이며 음수는 축소, 양수는 확대입니다. 과비중은 100×(현재비중-목표비중)/목표비중을 사용하며, 헤더의 임계값 이상이면 O 표시됩니다. 현금성 종목의 차액은 계좌별로 합산하여 표시합니다.

숫자 입력

☁ 서버 저장 / 공유

서버에 저장할 포트폴리오 ID를 입력합니다. 같은 ID와 비밀번호를 다른 기기에서 입력하면 동일한 데이터를 불러올 수 있습니다.

서버 저장은 현재 실행 중인 웹앱의 서버 API를 사용합니다. ID/비밀번호를 아는 사람은 해당 포트폴리오를 열 수 있으므로 비밀번호를 타인에게 공개하지 마세요.

🔗 다른 기기와 데이터 공유

아래 링크 또는 공유 코드를 다른 휴대폰/PC에서 열면 현재 포트폴리오 데이터가 그대로 불러와집니다. 별도의 서버 계정은 필요 없습니다.

주의: 공유 링크에는 포트폴리오 데이터가 포함됩니다. 종목·수량·평가금액 등이 들어 있으므로 공개 게시판 등에 올리지 말고 신뢰할 수 있는 기기/사람에게만 전달하세요.
